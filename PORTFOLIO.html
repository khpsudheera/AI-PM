01 · AI Product Discovery & Prototyping Functional Prototype Built

Instagram AI Search for Saved Content

Redesigning saved-content retrieval using multi-attribute semantic search to eliminate bookmark hoarding and retrieval drop-offs.

1. Problem & User Need

Users save high volumes of reels and posts but fail to retrieve them later due to high cognitive effort in visual scrolling and rigid folder categorization.

2. Proposed Solution

An AI-powered natural language search layer parsing multi-modal attributes: keywords, audio titles, creators, and contextual metadata.

3. Scope & Execution

Mapped query variations (conversational, associative), structured search UX heuristics, and built an interactive functional prototype in Lovable.

4. Outcomes & Validation

Actual: Built & tested interactive prototype.
Hypothesized Impact: Increase 30-day saved-post re-engagement and reduce search time.

Skills in Action

Semantic Search UX Design
Structured retrieval heuristics based on how human memory associates content (e.g., audio snippet + visual topic).
Rapid Prototyping (Lovable)
Built a functioning UI to test multi-attribute query parsing without waiting for production backend builds.
Problem Framing
Identified the 1-tap save vs. high-friction retrieval asymmetry as a retention bottleneck.
Lovable AI Product Concepts Semantic Search UX User Retrieval Flows
Context & Friction Points

Instagram's native "Saved" tab acts as a black hole: the barrier to save is trivial (one tap), but finding a saved asset weeks later requires exhaustive manual scrolling or rigid prior organization into folders that most users never maintain.

Proposed Discovery Flow

Introduce a top-level semantic search bar inside the Saved tab. The retrieval engine matches fuzzy natural language descriptors (e.g., "creamy Tuscan pasta recipe", "audio by Fred again") against post transcripts, audio tags, OCR on-screen text, and creator handles.

Limitations & Next Steps as PM

Limitations: Prototype was tested informally on personal devices without access to Instagram's actual index latency or compute budgets.
Next Steps: Conduct moderated usability tests on 20 heavy savers, write a technical PRD outlining edge cases (e.g., ambiguous queries, multiple audio matches), and design an A/B testing framework measuring Search Success Rate and Saved-to-Share conversion.

03 · Quick Commerce UX & Discovery Independent Product Analysis

Blinkit Quick-Commerce Product Case Study

Analyzing user purchasing psychology, impulse additions, and cart completion dynamics within 10-minute delivery environments.

1. Problem Context

Quick commerce relies on high average order value (AOV) to balance dark store fulfillment costs, yet users often complete single-item emergency orders.

2. Behavioral UX Analysis

Evaluated search ergonomics, category navigation, and checkout nudges for complementary add-ons (e.g., batteries with toys, milk with cereal).

3. Framework Application

Applied cognitive friction audits to cart flows, distinguishing high-intent searches from low-intent category browsing.

4. Proposed Solution

Proposed Interventions: Contextual cart recommendations triggered by time of day (morning breakfast bundles vs. late-night snacks).

Skills in Action

Behavioral Product Economics
Analyzed how minimum order thresholds interact with user panic buying vs. planned grocery replenishment.
Cart Friction Audit
Mapped steps from product search to payment confirmation, isolating points of latency.
Contextual Bundling UX
Hypothesized dynamic recommendation modules driven by time-of-day purchase patterns.
Quick Commerce AOV Optimization Friction Audits Behavioral Design
Context & User Urgency

In quick commerce, speed is both the value proposition and a barrier to high basket sizes. Users are goal-directed; interruptions cause abandonment. Recommendations must be frictionless 1-tap additions directly in the bottom checkout sheet rather than modal interstitials.

Next Steps for Validation

Propose A/B testing a 1-tap contextual add-on carousel at the bottom of the cart review screen to evaluate incremental lift in average order value without degrading checkout conversion.
